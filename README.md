# Homebrew Cask for vMLX (MLX Studio)

[vMLX](https://github.com/jjang-ai/vmlx) — The most complete MLX inference engine for Mac. Text, Image, Video & Audio generation on Apple Silicon.

## Install

```bash
brew tap jjang-ai/mlxstudio
brew install --cask mlxstudio
```

## Upgrade

```bash
brew upgrade --cask mlxstudio
```

## Uninstall

```bash
brew uninstall --cask mlxstudio
```

## Requirements

- macOS 14.0 (Sonoma) or later
- Apple Silicon (M1/M2/M3/M4)
